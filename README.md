# Bethel-Consult Desktop App

A desktop application built for **Bethel Methodist Medical Center** to automate hospital service reporting. Reads Excel records, groups 40+ medical services into 9 categories, and generates clean summary reports — no coding skills required by staff.

## Overview

Hospital service reporting at Bethel Methodist Medical Center previously relied on manually sorting and summarizing raw Excel records — a slow, error-prone process. This desktop app automates that workflow: it reads the raw Excel data, automatically classifies over 40 individual medical services into 9 defined categories, and outputs a clean, ready-to-use summary report. Staff interact with a simple graphical interface and don't need any technical or coding knowledge to use it.

## Tech Stack

- **Python** — core application logic
- **Tkinter** — desktop GUI
- **Excel Automation** (e.g. openpyxl/pandas) — reading records and generating reports

## Key Features

- ✅ Reads raw Excel service records directly
- ✅ Automatically groups 40+ medical services into 9 categories
- ✅ Generates clean, formatted summary reports
- ✅ Simple GUI — no coding skills required by staff
- ✅ Reduced manual reporting time significantly
- ✅ Deployed and used in a real hospital environment
- ✅ Built solo, from requirements gathering to delivery

## Requirements

- Python 3.x
- Tkinter (included with standard Python installations)
- Excel automation library (e.g. `openpyxl` or `pandas`)
